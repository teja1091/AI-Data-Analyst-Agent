# AI Data Analyst Agent

## Project Vision

Build an AI-powered data analytics platform
that can understand and analyze uploaded datasets.

## Core Features

1. Data ingestion
2. Automated data profiling
3. Data cleaning
4. Machine learning pipelines
5. Anomaly detection
6. Conversational AI agent
7. Automated insights
8. Report generation

## Development Approach

Learn and implement each technology
incrementally while building the application.
